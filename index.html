    IMPLEMENTATION STATUS

    A laboratory, not a product claim.

    This first release runs the simulation and actual neural-weight updates entirely in your browser. Rendering is separate from the simulation and training workers.

    Implemented

    Acceleration-limited flight, conservative collision geometry, four home/arena scenarios, reactive procedural insect, delayed/noisy target estimates, six range rays, baseline navigation, a residual DQN, deterministic seeds, weight import/export and held-out-seed comparison.

    Not yet implemented

    Six-degree-of-freedom rotor physics, calibrated mosquito aerodynamics, camera-image detection, estimated occupancy/SLAM, robust moving-obstacle prediction, battery/device models, a fruit-fly connectome, and physical electrical effectiveness. These are explicit work packages in the brief.

    Important shortcuts

    The safety filter uses the simulator's exact obstacle map. The insect has idealized proximity cues. Reward shaping uses ground truth. Training evaluation changes seeds, not home layouts. Visual wing and rotor motion are illustrative. Contact is not electrocution.

    All software tests concern this implementation, not safe household deployment. No electrical system can be enabled from this application.
